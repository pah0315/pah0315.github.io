Program

Hermes EA is a personal assistant text service run by Peter Harrison for his own use. It sends reminders and schedule updates and replies to questions that the user texts to it. Messages are written by an AI assistant and can contain mistakes.

Who may enroll

Only the account owner, Peter Harrison. The service is not open to the public and no other phone number is added.

How enrollment works

The user enrolls by texting the keyword EA to the program number from his own mobile phone. The program replies with a confirmation.

Message frequency

Varies with use, up to about 20 messages per day in total, in both directions.
